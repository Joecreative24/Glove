# Intelligent Glove for Arabic Sign Language — Firebase Backend

Backend & database layer for a Flutter app that pairs with a **smart glove**
used by deaf/mute people to communicate in **Arabic Sign Language**. The glove
streams sensor data; the app recognises gestures, runs translation sessions,
shows a live Arabic message feed, and tracks devices, battery and connection
health — all on **Firebase**.

> **Scope:** this repository is the *backend* responsibility — Authentication,
> Cloud Firestore schema, security rules, the Flutter data layer
> (`lib/backend/`), optional Cloud Functions, and full documentation. The UI
> screens (Home / Services / Profile tabs etc.) plug into the
> [`GloveBackend`](lib/backend/glove_backend.dart) facade.

## Firebase services used

* **Authentication** — email/password, **Google Sign-In**, password reset.
* **Cloud Firestore** — 8 collections (`users`, `usernames`, `devices`,
  `connectionLogs`, `gestureReadings`, `translationSessions`,
  `realtimeMessages`, `alerts`).
* **Cloud Storage** — profile photos.
* **Cloud Messaging** — push notifications for alerts.
* **Cloud Functions** *(optional, Blaze plan)* — FCM fan-out + secure
  username reservation + optional server-side alert/aggregation.

## The data relationship

> **User** `1‑to‑many` **Devices** → **Device** produces **GestureReadings**
> → GestureReadings **feed** a **TranslationSession** → the session **outputs**
> **RealtimeMessages**. Devices also emit **ConnectionLogs** and **Alerts**.

See the full ER diagram and field-by-field schema in
[`docs/DATABASE_SCHEMA.md`](docs/DATABASE_SCHEMA.md).

## Quick start

```bash
# 1. install tooling
npm install -g firebase-tools
dart pub global activate flutterfire_cli

# 2. pull packages
flutter pub get

# 3. connect to your Firebase project (generates lib/firebase_options.dart)
flutterfire configure

# 4. deploy rules + indexes
firebase deploy --only firestore:rules,firestore:indexes,storage
```

Then initialise and use it:

```dart
await Firebase.initializeApp(options: DefaultFirebaseOptions.currentPlatform);

final backend = GloveBackend();
await backend.registerWithEmail(
  fullName: 'Sara Ali', email: 'sara@example.com',
  password: 'strongPass123', username: 'sara_ali',
);
```

📖 **Full instructions:** [`docs/SETUP_GUIDE.md`](docs/SETUP_GUIDE.md).

## Key flows (all on `GloveBackend`)

| Auth | Devices | Translation |
|------|---------|-------------|
| `registerWithEmail` | `addGlove` | `startTranslation` |
| `signInWithEmail` | `renameGlove` | `recordGesture` |
| `signInWithGoogle` | `setConnectionStatus` | `endTranslation` |
| `sendPasswordReset` | `reportBattery` | `triggerSos` |
| `isUsernameAvailable` | `sessionHistory` | analytics via `AnalyticsService` |
